
# Task Manager Web

## Présentation du projet

Task Manager Web est une application web de gestion des tâches
développée dans le cadre du module DevOps.

Elle permet aux utilisateurs d'organiser leurs activités
quotidiennes, de suivre leur progression et de gérer
facilement leurs tâches.

## Objectifs

- Ajouter de nouvelles tâches.
- Marquer les tâches comme terminées.
- Supprimer les tâches.
- Consulter les statistiques.
- Suivre le pourcentage de progression.

## Technologies utilisées

- HTML5 : structure de l'application.
- CSS3 : mise en forme et design responsive.
- JavaScript : logique et interactions.
- Git : gestion des versions.
- GitHub : hébergement et collaboration.

## Installation et exécution

1. Télécharger ou cloner le projet.
2. Ouvrir le dossier task-manager.
3. Ouvrir le fichier index.html dans un navigateur.

Aucune installation supplémentaire n'est nécessaire.

## Fonctionnalités

- Gestion dynamique des tâches.
- Validation des champs.
- Détection des tâches en double.
- Calcul automatique des statistiques.
- Barre de progression.
- Interface responsive.
